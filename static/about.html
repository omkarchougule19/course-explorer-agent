What this is

A course catalog browser for UIUC plus a natural-language assistant on top of it. Ask a question in plain English — "which CS 225 sections have seats left," "what's the prerequisite for MATH 415," "when's the last day to drop a class this fall" — and the assistant answers from real data, not a guess.

How answers are generated

Every question goes through one of two tools, picked by the assistant itself:

  • Structured SQL. Questions about sections, seats, meeting times, grade distributions, prerequisites, or academic-calendar deadlines get translated into an actual SQL query against the catalog database and run for real. A critic/repair step catches and fixes malformed queries before they're executed.
  • Semantic search. Vaguer, topic-shaped questions ("courses about machine learning") are expanded into several related search phrases, each matched against course description embeddings, and the ranked results are merged into one set.

Every answer that uses real data ends with a sources line naming exactly which dataset it drew from and how fresh that data is. Answers outside the assistant's scope are refused rather than guessed at.

Data sources and freshness

Course, section, and enrollment data comes from UIUC's public Course Explorer catalog. Grade distribution history comes from a separately published, publicly available dataset. All of it is a periodic snapshot pulled on a schedule, not a live feed — see the data freshness page for exactly how current each subject and term is right now. This is not the registrar and should not be used as one; always confirm enrollment, deadlines, and requirements against the official university systems before acting on them.

What it isn't

This is an independent student project, built and run on personal infrastructure. It is not affiliated with, endorsed by, or sponsored by the University of Illinois, and it is not the university's own Course Explorer tool. No account, login, or personal information is collected — questions asked here are not tied to any identity. It's also still under active development, running on a small, shared free LLM budget — the assistant may briefly stop answering once that daily budget runs out, though browsing, search, prerequisites, and grade history keep working regardless.
