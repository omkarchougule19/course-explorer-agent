Ask the Course Assistant

Ask about courses, sections, instructors, or gen-eds. Follow-ups work — it remembers the last few turns. Answers come from the latest snapshot of each department, not a live feed.

This project is under active development and runs on a small, shared free LLM budget. If the daily limit below is reached, the assistant may stop answering for a while — try again later. Browsing, search, prerequisites, and grade history below always keep working regardless.
