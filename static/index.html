Department Data

Each department is refreshed on demand. Hit Sync to request a refresh — it's picked up within 24 hours (departments synced in the last 7 days are already current). The number is how many refreshes have been requested since the last sync. The list is ordered by pending requests, then by how stale the data is; use the filter or Show all for the rest.
